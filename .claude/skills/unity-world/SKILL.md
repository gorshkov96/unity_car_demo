# Мир, трафик, производительность

Детали — [мир](../../../docs/unity/08-world-building.md),
[трафик и ИИ](../../../docs/unity/07-traffic-ai.md),
[производительность](../../../docs/unity/06-performance.md).

## Мир

- Дороги — пакет **Splines 2.9.0**, свой сплайн-редактор не пишем.
- Меш дороги строим **кодом** через `SplineMesh.Extrude`, а не компонентом в инспекторе:
  сцену должно быть можно пересобрать скриптом.
- Блокаут окружения — **ProBuilder 6.1**. ProGrids и Polybrush не ставить.
- **Terrain нам не нужен**: Unity заявила замену на новую Worldbuilding System, а наша
  карта — городская, из мешей.

## Трафик и агенты

- **Машины ездят по сплайнам, а не по NavMesh.** NavMesh не знает про полосы и развороты.
- **Пешеходы — на `NavMeshAgent`** (AI Navigation 2.0.14): здесь как раз его сильная сторона.
- Стартуем просто: обычные `MonoBehaviour` + `UnityEngine.Pool.ObjectPool<T>`.
  До ~200–300 активных агентов этого хватает. Сначала измерить, потом усложнять.
- Потолок роста — Jobs + Burst без ECS. Полный DOTS/ECS в демо такого размера не оправдан.

## Производительность

- Бюджет: 60 FPS = **16.66 мс на кадр**, CPU и GPU считаются отдельно, каждый должен влезть.
- Включить модуль **Highlights** в профайлере — по умолчанию он выключен.
- Спавн только через пулы. `Instantiate`/`Destroy` в кадре — источник фризов из-за сборщика мусора.
- Оптимизируем по замеру, а не по ощущению. Сначала профайлер, потом правки.
